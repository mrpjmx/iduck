## 静态博客的优势

用了这么多年动态博客，换了无数套 CMS，最后还是回到了静态博客。原因很简单：

- **速度**：纯 HTML 文件，CDN 加速，毫秒级加载
- **安全**：没有数据库，没有 PHP/数据库漏洞
- **成本**：GitHub Pages / Vercel 免费托管
- **维护**：不用操心服务器、数据库备份
- **版本化**：文章用 Git 管理，改错了随时回滚

## 写作体验

用 Markdown 写文章是程序员的浪漫。VSCode + 图漾 + Git，就是完整的写作环境。

> 最好的写作工具，就是不打断写作思路的工具。

## 结论

静态博客不是倒退，而是回归本质：内容为王。对于真正想记录的人来说，写作体验和内容本身才是核心。
